# Kasse – Weihnachtsmarkt

Einfaches Kassensystem als installierbare Web-App (PWA) für iPad und Android-Tablets: Verkäufe zählen, Wechselgeld, Bons mit QR-Code und PDF, Kassensturz und Kassenbericht. Läuft ohne Server und offline.
